# 📚 BookTracker - Aplicativo Móvel de Gestão de Livros

Aplicativo desenvolvido em **React Native** com **Expo** para gerenciamento de biblioteca pessoal, criado como requisito para avaliação acadêmica.

## 🚀 Funcionalidades
- **Tela Inicial (Home)**: Lista de livros cadastrados com busca em tempo real por título e opção de exclusão.
- **Tela de Detalhes**: Visualização completa das informações do livro selecionado (autor, número de páginas e status de leitura).
- **Tela de Cadastro (Add)**: Formulário interativo para adicionar novos livros à biblioteca com atualização de estado em tempo real.
- **Navegação estruturada**: Utilização de `@react-navigation/native` e `@react-navigation/stack`.
- **Componentrização**: Uso de componentes reutilizáveis (`CustomButton` e `BookCard`).

## 🛠️ Tecnologias Utilizadas
- React Native / Expo
- React Navigation (Stack Navigator)
- JavaScript (ES6+)
